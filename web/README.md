# 映场 · 纪录片放映周

在本目录运行 `npm run dev`，再打开 [本地预览](http://127.0.0.1:4173/)。需要 Node.js，无需安装 npm 依赖。

- **身份选择**提供管理员登录和观众登录。管理员账号为 `admin`，密码为 `admin123`。密码使用浏览器的掩码输入，连续输错三次返回身份选择页。观众点击入口即可进入片目页。
- **管理员后台**支持按片名或片号查找片目、新增、查看、修改和删除。删除片目会清理关联评价。也可查看全部评价，或输入分界点统计每部影片在各综合分区间的人数。
- **片目**顶部的展映栏支持鼠标悬停展开封面，背景随当前影片切换。可用栏内按钮或键盘左右键换片，手机上可横向滑动。下方片目网格支持按片名检索和按类别筛选。开启系统减少动态效果时，网页关闭放大过渡。
- **榜单**可切换综合、内容、画面和讲解。综合分沿用 `(2 × 内容分 + 画面分 + 讲解分) ÷ 4`，榜单按平均分、评价人数、片号依次排序。
- **影片详情**可填写观众编号，为三项指标各选 1 至 5 分，并写短评。使用同一个观众编号再次评价同一部影片时，更新原记录。

网页首次使用样例片目和评价。管理员和观众共用 `data/catalog.json`，文件在首次保存时创建。旧网页保存在同一浏览器、同一地址的评价会尝试自动导入。原 C++ 程序使用独立的文本数据文件。管理员会话保存在本地服务的内存中，服务重启后需重新登录。

`src/app.js` 负责路由和观众端，`src/admin.js` 负责身份选择、登录和后台操作，`src/catalog.js` 负责样例数据和评分计算，`scripts/catalog-api.mjs` 负责权限校验和数据存储。海报来自第 1 版生成视觉稿及同风格独立生成素材。新片目会显示统一的封面占位图。「映场」使用生成的画幅标志，操作图标来自 [Bootstrap Icons](https://github.com/twbs/icons)。
